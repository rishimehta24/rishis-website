# Rishi Mehta — personal site

Static, two files, no build step.

- `index.html` — all content. Edit text directly.
- `styles.css` — palette and type at the top (`:root`). Colours are the Ascenix palette: `#0CC7ED` / `#E8E8E8` / `#0F0F14`. Font is Inter.

## Run locally

```sh
npx serve .
```

## Deploy

Any static host: Vercel, Netlify, Cloudflare Pages, GitHub Pages.

## Updating

- **Now**: edit the list and the month label.
- **Off duty checklist**: add `class="done"` to an `<li>` to check it off.
- **Key phrases** in the story bullets are wrapped in `<span class="u">` for the dotted underline.
